# 匿名遥测说明

从 `1.0.0-beta.8` 起，软件会向开发者自建的 Sentry 项目上报以下数据，用于定位"哪个任务在哪个版本上失败率变高"：

- 任务层面：每个任务的开始/结束/成功/失败，失败时卡住的节点名，以及主动捕获到的异常信息；
- 运行环境：操作系统与架构、CPU 与显卡型号、内存大小、客户端与资源版本号，以及一个由机器标识哈希出来的匿名设备 ID（用于区分不同设备，不含用户名）；
- 失败现场：任务识别失败时的一张游戏截图，和该次任务的部分诊断日志。截图可能包含画面里的昵称、进度等信息。

**不上传**：账号与密码、聊天内容等个人身份信息；客户端已显式关闭 SDK 的默认 PII 上报（`SendDefaultPii=false`），也不会自动附带 IP 或用户信息。

**想关掉**：

- 打开设置，下拉找到 `关于我们`，在其中下拉找到 `帮助改进软件`，关掉它即可。

关闭后重启软件将不再上报。

<details>
<summary>数据由谁接收</summary>

Sentry 服务由开发者本人注册与持有，数据只用于本项目自身的稳定性改进，不对外共享。上报所需的 DSN 是公开标识（客户端密钥本就随包分发），它不等于账号，也无法用于读取数据。
</details>
