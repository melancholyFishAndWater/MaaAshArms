# 问题上报

1. 遇到问题先重启电脑，不行就重新下载并解压最新版 [Github](https://github.com/melancholyFishAndWater/MaaAshArms/releases)

2. 确定不是您的个人问题，从官方仓库issues [Github](https://github.com/melancholyFishAndWater/MaaAshArms/issues)

3. 准备好您的**上报材料**，开发者不是大仙，不能靠算卦来判断出错误的原因，请尽可能提供详细的信息，能方便开发者快速定位问题

4. 最重要的材料有：程序目录文件夹下名叫 `logs` 和 `debug` 的两个文件夹，除此之外您还可以视情况录制软件运行出错的过程
